# Gallery App

Bienvenue dans la Gallery App, une application de galerie simple et élégante construite avec HTML et CSS. Ce projet est idéal pour afficher des collections d'images de manière organisée et esthétique.

## À propos du projet

La Gallery App est une base de code HTML/CSS conçue pour créer des applications de galerie. Elle est parfaite pour les développeurs souhaitant une solution légère et personnalisable pour afficher des images.

## Construit avec

- HTML5
- CSS3

## Prérequis

Aucun prérequis spécifique n'est nécessaire pour utiliser ce projet. Assurez-vous simplement d'avoir un navigateur web moderne.

## Installation

1. Clonez le dépôt :

    ```bash
    git clone https://github.com/matthieu-27/gallery-app.git
    ```

2. Ouvrez le fichier `index.html` dans votre navigateur pour voir la galerie en action.

## Utilisation

Pour utiliser la Gallery App, il suffit de modifier le fichier HTML pour ajouter vos propres images et styles CSS. Vous pouvez personnaliser la mise en page et les effets visuels selon vos besoins.
